📊 V8 Upbit KRW 백테스트

Upbit KRW 완료 5분봉과 실시간 Worker의 동일 Score 계산식을 사용합니다. v8.1.0은 기존 단순 TP/SL뿐 아니라 실전 SELL 조건 재현과 ATR 기반 TP1·TP2·트레일링 연구 모드를 제공합니다. 신호는 완료봉에서 판정하고 다음 5분봉 시가에 진입합니다. 같은 봉에서 손절과 목표가가 모두 닿으면 보수적으로 손절을 우선합니다. 외부 거시/뉴스/예측시장 점수는 과거시점 데이터가 완전하지 않아 현재 백테스트에는 아직 포함하지 않습니다.

개선형은 TP1에서 50% 부분익절 후 남은 50%를 TP2 이후 더 촘촘한 트레일링으로 추적하며, BTC Risk-Off/Crash·EMA/상대모멘텀 약화·Score 하락 등 실전 SELL 조건도 함께 평가합니다. 60~90일 ALL은 데이터 수집에 수분이 걸릴 수 있습니다.
아직 실행하지 않았습니다. 첫 실행은 Upbit 과거 데이터를 페이지 단위로 받아오므로 시간이 걸릴 수 있으며, 같은 세션에서는 더 긴 기간의 캐시를 재사용합니다.
🧪 조건 탐색 + 워크포워드 + 비용 스트레스

최적화는 연구 도구입니다. 최적값을 자동으로 실시간 Worker에 적용하지 않습니다. 실전 설정을 바꾸려면 worker/wrangler.toml의 값을 변경한 뒤 Worker를 재배포해야 합니다.
